## Pasos manuales (no los puede hacer el código)

### 1. Clave de Anthropic

1. En https://console.anthropic.com → **API Keys**: confirmar que la clave comprometida figura revocada y crear una nueva (idealmente en un workspace solo para este servicio, con límite de gasto mensual).
2. En Railway → servicio → **Variables**: reemplazar `ANTHROPIC_API_KEY` por la nueva. **No** subirla al repo ni a GitHub Secrets (el cron no la usa).
3. Después del redeploy: `curl https://comprar.ecosistematransparencia.com.ar/api/diagnostico?forzar=true` debe mostrar `"ia": {"valida": true, ...}`.

Como el incidente fue en Railway, rotar también lo que vivía en las mismas variables: `ADMIN_KEY`, `GA_API_SECRET`, la contraseña de PostgreSQL (Railway → base → **Settings** → regenerar credenciales; `DATABASE_URL` se actualiza sola) y revisar en GitHub → **Settings → Applications** que la integración de Railway sea la esperada. `TGN_TOKEN`, `MAIL_USER`/`MAIL_PASS` están en GitHub Secrets: rotarlos si alguna vez se copiaron a Railway.

### 2. Arrancar `app_extendida_v2` en Railway

Railway → servicio → **Settings → Deploy → Custom Start Command**:

```
sh -c "uvicorn app_extendida_v2:app --host 0.0.0.0 --port ${PORT:-8000}"
```

(El `Dockerfile` sigue arrancando `app_extendida:app`; el comando personalizado lo reemplaza sin tocar el archivo. Para volver atrás, borrar el comando.)

### 3. Recuperar del 22/10 a hoy

En un clon de `desarrollo` en esta PC (Argentina):

```
python tools/actualizar_desde_pc.py --dry-run     # lista los días que faltan
python tools/actualizar_desde_pc.py --publicar    # los genera y hace push a desarrollo
```

Para que el reporte del día incluya TGN, la PC necesita la variable `TGN_TOKEN`
(hoy solo está en GitHub Secrets): `setx TGN_TOKEN "<token de presupuestoabierto.gob.ar>"`
y abrir una consola nueva. Sin ella el ciclo funciona igual y TGN queda vacío
(así se generó el reporte del 30/10/2026: BORA 71 avisos, Comprar 12, TGN 0; para
rehacerlo con TGN, borrar `data/2026-10/*_2026-10-30.xlsx` y volver a correr el script).

El push a `desarrollo` redespliega Railway (si el deploy automático sigue conectado, ver la fila "extra" del diagnóstico) y el dashboard pasa a mostrar el último día.

La PC tiene que estar encendida en esos horarios; si un día no lo está, la corrida siguiente completa los días que falten, y la alerta de las 14:00 avisa por mail.
